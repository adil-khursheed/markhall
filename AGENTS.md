# Agents

This project uses the Payload CMS skill at `.agents/skills/payload/`.
Start with `.agents/skills/payload/SKILL.md` for a quick reference, then see `.agents/skills/payload/reference/` for detailed docs.

## Rules

- **Never commit changes.** The user reviews all changes before they are committed. Leave work uncommitted at the end of every task; do not run `git commit` (or `git add` with the intent to commit) unless the user explicitly asks for a commit in that turn.
